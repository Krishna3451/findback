# Captured FindBack story

[Play the narrated demo](FindBack-Miles-story-demo.mp4). This edit uses the full 1600×900 interactive capture recorded before the first story post, uniformly scaled 1.2× to 1920×1080. It shows actual message arrivals, real agent responses, and any typing/progress displayed by the app. The people and objects are fictional.

Arrival windows keep their captured timestamp cadence. The edit removes reviewed static waits, adds reading time by holding real frames, and uses 10-frame (0.417s) crossdissolves with explicit 5-frame handles. It does not invent messages, typing, progress or interface elements. No old take, crop or padding is used. The 1.2× upscale preserves the full source viewport. This narrated cut is edited rather than a continuous record of every elapsed second.

The 188.918-second normal-pace master AAC narration by Miles - Confident, Upbeat and Smooth is copied without editing. The audio stream hash is verified bit-for-bit. The case ends at approved collection, before handover and receipt. The source hashes, native capture windows, real-frame holds and dissolve times are recorded in interactive-manifest.json.
